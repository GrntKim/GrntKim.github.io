## 2. 해설
입력의 형태는 길이 n의 int 배열로도 충분하다. 1000을 넘지 않는다고 했으니 넉넉히 1005 길이의 배열을 설정해주자 
```cpp
int land[1005];
```

일단 입력이 0 0 x y z ... 0 0 이런식으로 친절하게 들어오니 그냥 n개의 입력받기만 있으면 된다 
```cpp
for (int i = 0; i < n; i ++) {
    int h; cin >> h;
    land[i] = h;
}
```

그다음, 실제 순회는 2번 인덱스부터, n-3 인덱스까지 돌면 된다. 그 바깥은 무조건 0이므로.  
순회하면서 이제 핵심 로직이 나온다.  
좌우로 두 칸 이상 공간이 있는 세대라는 말은 무엇인가?  
좌 우 두칸(4개) 의 건물 높이의 최대값을 구한 다음, 현 건물의 높이에서 빼주면 된다.  
그 값이 양수라면, 우리가 찾는 세대이므로 정답에 더해주면 된다.  
```cpp
for (int i = 2; i < n-2; i++) {
    int diff = land[i] - max(max(land[i-2], land[i-1]), max(land[i+1], land[i+2]));
    if (diff > 0) ans += diff;
}
```


## 3. 완성 코드 
```cpp
#include <iostream>

using namespace std;

int land[1005];

int main(void) {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    for (int t = 1; t <= 10; t++) {
        int ans = 0;

        int n; cin >> n;
        for (int i = 0; i < n; i++) {
            int h; cin >> h;
            land[i] = h;
        }

        for (int i = 2; i < n-2; i++) {
            int diff = land[i] - max(max(land[i-2], land[i-1]), max(land[i+1], land[i+2]));
            if (diff > 0) ans += diff;
        }

        cout << '#' << t << ' ' << ans << '\n';
    }
    return 0;
}

```

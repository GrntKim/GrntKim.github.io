## 2. 해설
유명한 문제다. 처음 접할때는 보통 이차원 배열을 가지고 백트래킹으로 접근하는데, 어차피 열/행에 퀸이 두 개 이상 존재할 수 없다는 점을 관찰해보면 1차원 배열로도 충분히 가능하다. 
```cpp
int board[15];
```
여기서 board[r] = c 이냐 board[c] = r 이냐 하는 차이는 스타일의 없이이지만, 여기서는 후자를 선택한다. 1차원 배열의 각 요소를 열로 보고, 그 열에는 몇번째 행에 퀸이 위치해있는지 생각하기로 한다.  

그렇다면 백트래킹은 이렇게 진행될 것이다.  

```cpp
void nq(int c) { // c 열에 대한 탐색
    if (c == n) { // n개의 퀸을 다 놓았다면 정답 갯수에 추가 후 종료
        ans++;
        return;
    } 

    for (int i = 0; i < n; i++) { // 가능한 행 번호에 대해
        board[c] = i; // 일단 놓아본다
        if (promising(c)) // 이 열에 올바르게 놓았다면? 
            nq(c+1); // 다음 열에 대해 탐색(재귀)
    }
}
```
promising 을 만족하지 못한 사례에서는 자연스레 탐색을 종료하게 된다.  
그럼 promising 은 어떻게 옳게 놓였음을 판별할 것인가?  
- 이 앞 열까지 놓인 퀸들에 대하여
1. 같은 열에 놓인 퀸이 없어야 한다
2. 대각선 방향에 놓인 퀸이 없어야 한다

이 두 조건을 만족하면 된다. 이것을 코드로 옮겨 판단함수를 만들어보면
```cpp
bool promising(int c) {
    for (int i = 0; i < c; i++) {
        if (board[c] == board[i] || abs(board[c] - board[i]) == (c - i))
            return false;
    }
    return true;
}
```
or 식의 좌변에는 이미 같은 값이 존재하는가를 판별, 우변에서는 대각선을 보게 되는데, 대각선이다 -> '두 좌표의 기울기가 1이다' 이고, 항상 i < c 이지만, 이전 행이 더 클 수 있으므로 항등식의 좌변에만 절댓값을 취해주면 된다.


## 3. 완성 코드 
```cpp
#include <iostream>

using namespace std;

int ans, n;
int board[15];

bool promising(int c) {
    for (int i = 0; i < c; i++) {
        if (board[c] == board[i] || abs(board[c] - board[i]) == (c - i))
            return false;
    }
    return true;
}

void nq(int c) {
    if (c == n) {
        ans++;
        return;
    }

    for (int i = 0; i < n; i++) {
        board[c] = i;
        if (promising(c))
            nq(c+1);
    }
}

int main(void) {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    freopen("input.txt", "r", stdin);
    int T; cin >> T; 
    for (int t = 1; t <= T; t++) {
        ans = 0;
        cin >> n;
        nq(0);
        cout << '#' << t << ' ' << ans << '\n';
    }
    return 0;
}
```
